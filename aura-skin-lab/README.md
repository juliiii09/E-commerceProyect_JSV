# MEVE · Aura Skin Lab (`aura-skin-lab`)

Aplicación web **Next.js 16.4.2 (App Router + Turbopack)** de **MEVE · Aura Skin Lab**: e-commerce de dermocosmética con ecosistema de Inteligencia Artificial de estética minimalista (*Quiet Luxury*) y Panel de Administración con validación criptográfica de credenciales.

Consulta la documentación completa de arquitectura, módulos de IA, estructura y credenciales de acceso en el [**README principal del repositorio**](../README.md).

## Comandos Rápidos

```bash
# Iniciar servidor de desarrollo en http://localhost:3000
npm run dev

# Verificar tipos de TypeScript
npx tsc --noEmit

# Ejecutar linter ESLint
npm run lint

# Compilar versión de producción
npm run build
```
